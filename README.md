# SAQR — صفحة تعريفية لخدمة أمن سيبراني

صفحة تسويقية بلغة عربية (RTL) لخدمة أمنية سيبرانية افتراضية باسم "SAQR"، تعرض كيف تكتشف
منصة مثل هذه البرمجيات الخبيثة والدود ومحاولات الاختراق، وتُبلّغ عنها جهة مسؤولة (فريق أمن
داخلي أو جهة تنظيمية). الصفحة تعريفية بالكامل: لا تفحص أو تحمي أي جهاز فعليًا، وتحتوي على
نموذج لطلب استشارة/عرض تجريبي يُرسل عبر Netlify Forms.

## التقنيات المستخدمة

- [TanStack Start](https://tanstack.com/start) — إطار React مع توجيه وعرض من جهة الخادم (SSR)
- React 19 + TypeScript
- Tailwind CSS 4
- Netlify Forms لاستقبال طلبات التواصل

## التشغيل محليًا

```bash
npm install
npm run dev
```

يفتح الموقع على `http://localhost:3000`.

> ملاحظة: نماذج Netlify Forms لا تعمل في بيئة التطوير المحلي، وتحتاج نشرًا فعليًا على Netlify
> لاختبار استقبال الطلبات.

## البناء للإنتاج

```bash
npm run build
```
